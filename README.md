# Royal Wellness

Κατάλογος προϊόντων Herbalife Nutrition. Ανεξάρτητο Μέλος Herbalife.

Στατική ιστοσελίδα, χωρίς εξωτερικές εξαρτήσεις. Οι παραγγελίες γίνονται μέσω
WhatsApp.

## Δομή

| Φάκελος | Περιεχόμενο |
|---|---|
| `docs/` | Η ιστοσελίδα (παράγεται αυτόματα — μην την επεξεργάζεστε) |
| `catalogo/productos.json` | Τα προϊόντα: η μοναδική πηγή δεδομένων |
| `scripts/build.py` | Ο generator |

## Ενημέρωση

```
actualizar.bat --publicar
```

Διαβάζει το `catalogo/productos.json`, ξαναχτίζει το `docs/index.html` και το
δημοσιεύει.

---

Τα προϊόντα Herbalife Nutrition δεν είναι φάρμακα και δεν προορίζονται για τη
διάγνωση, θεραπεία ή πρόληψη ασθενειών.
